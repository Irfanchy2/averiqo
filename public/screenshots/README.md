# Product screenshots

Put real Averiqo screenshots here. A file named after a slot replaces the
built-in UI preview automatically (`.webp`, `.png`, `.jpg`, `.jpeg` or `.avif`).

Desktop (16:10 works best, at least 1600px wide):
dashboard, crm, invoices, projects, employees, documents, vehicles,
reports, whatsapp, ai, companies

Mobile (portrait phone screens, about 9:19.5):
mobile-dashboard, mobile-invoice, mobile-tasks

Example: `crm.png`, `mobile-dashboard.webp`
